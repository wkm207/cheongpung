# Country of Wind

고전 한국 온라인 RPG 감성의 **오프라인 싱글 RPG**입니다. 아이패드·아이폰 홈 화면에 설치하면 비행기 모드에서도 실행됩니다.
그래픽·지명·캐릭터·기술 이름은 모두 이 프로젝트에서 새로 만든 오리지널입니다(외부 그림·소리 파일 없음).

## 게임 내용
- **직업 4종**: 전사 · 도적 · 주술사 · 도사 — 직업마다 기술 14개(기본 8 + 승급 6)
- **승급(3차까지)**: 마을의 **사범 청운**에게서 레벨·재료·금전을 갖추고 승급
  | 직업 | 1차 (Lv15) | 2차 (Lv30) | 3차 (Lv45) |
  |---|---|---|---|
  | 전사 | 검객 | 무장 | 검성 |
  | 도적 | 협객 | 자객 | 암왕 |
  | 주술사 | 술객 | 대주술사 | 천기술사 |
  | 도사 | 도인 | 진인 | 신선 |
- **기술창(K)**: 레벨이 되면 금전을 내고 직접 배우고, 1~5 슬롯에 넣어 사용. 돌진·순간이동 기습(풍영보)·연쇄번개·저주·마비·독·은신·지속 회복·일직선 베기·운석(천벌) 등
- **장비 5칸**: 무기 · 투구 · 갑옷 · 목걸이 · 반지. 가방에서 눌러 능력치 비교(▲/▼), 한 번 더 누르면 착용, "더 좋은 장비 한 번에 착용" 버튼. 1~3차 전용 장비
- **퀘스트(L)**: 촌장(메인 10단계), 약방 할멈·대장장이·포목점·방물장수(수집 퀘스트, 반복 포함). 머리 위 **!** = 새 부탁, **?** = 완료 보고
- **맵**: 청풍촌(기와집·초가·돌담·장승) → 토끼 들판 → 늑대 언덕 → 깊은 산 → 이무기 늪 → 설원 고개 → 흑룡 동굴 / 여우 숲 → 도깨비 굴 → 구미호 굴
- **보스**: 구미호(Lv20) · 이무기(Lv30) · 흑룡(Lv50)
- **저장 슬롯 4칸**, 15초마다 자동 저장, 백업 내보내기/불러오기
- **운영자(GM) 도구(G)**: 레벨·승급·금전·아이템·순간이동·소환·무적·속도·기술 전부 배우기

## 조작
| 터치 | 키보드 |
|---|---|
| 왼쪽 아래 방향 버튼(또는 조이스틱, 메뉴에서 변경) | 방향키 / WASD |
| 다른 방향을 짧게 누르면 제자리에서 돌아서기 | 같음 |
| 공격 버튼(누르고 있으면 연속 공격) | Space |
| 아래 조작판 단축키 칸 1~5(가운데 숫자 = 남은 초) | 1 ~ 5 |
| 🌿 / 💧 물약 | Q / E |
| NPC 앞에서 공격 버튼, 또는 NPC 누르기 → 대화 | Space |
| 가방 · 기술 · 정보 · 퀘스트 · 메뉴 · GM (아래 조작판 버튼) | I · K · C · L · M · G (Esc 닫기) |
| 대화창 입력줄 누르기 → 말하기 (`/`로 시작하면 운영자 명령) | Enter |
| 오른쪽 위 미니맵 누르기 → 켜기/끄기 | N |

몬스터는 옆에 붙은 뒤 **잠시 몸을 움찔(붉게 떨림)한 다음** 공격합니다. 그 사이 한 칸 물러나면 피할 수 있어, 한 칸씩 빠졌다 치는 플레이가 됩니다.

## 아이패드·아이폰에 설치하기 (오프라인 실행)
서비스 워커가 HTTPS에서만 동작하므로, 이 폴더를 HTTPS 정적 호스팅(GitHub Pages, Netlify 등)에 올린 뒤:
1. Safari로 주소 접속 → 타이틀 화면이 뜰 때까지 한 번 기다리기(파일이 기기에 저장됨)
2. 공유 버튼 → **홈 화면에 추가**
3. 비행기 모드에서 홈 화면 아이콘으로 실행

> 게임 파일을 고쳐서 다시 올리면, 인터넷이 될 때 한 번 실행하면 뒤에서 새 파일을 받아 두고 **다음 실행부터** 새 버전이 됩니다.
> 저장 데이터는 기기 안에만 있습니다. 가끔 `메뉴 → 백업 내보내기`로 백업해 두세요.

## 개발
```bash
npm test
```
```bash
npm run serve
```
`npm run serve` 후 http://localhost:8080 에서 확인합니다. 주소 끝에 `?debug`를 붙이면 콘솔에서 `cheongpung.game()`으로 게임 상태를 볼 수 있습니다.
아이콘은 `npm run icons`로 다시 만듭니다. 새 JS 파일을 추가하면 `sw.js`의 `ASSETS` 목록에도 넣어야 오프라인에서 열립니다.
